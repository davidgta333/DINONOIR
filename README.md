# DINONOIR
A game about a detective dinosaur.

SYSTEM REQUIREMENTS

This is a small game and can run on any computer. It runs on Windows 10 and Windows 11. To play the game unzip the file, double click on .exe and click yes if a pop-up appears.

FEATURES
This game contains Dialogue mechanic, a hub with selectable levels, jumping and shooting mechanics also.

HOW IT WORKS
The game was made in Unity, using c# coding language. I decided to use Unity because i was already familiar with the interface.
